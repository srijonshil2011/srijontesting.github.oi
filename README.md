# সৃজনশীল তরুণ সংঘ — GitHub Pages Website

1. Repository-তে সব ফাইল আপলোড করুন।
2. `assets/images/logo.png`-এ সংগঠনের আসল লোগো দিন।
3. `assets/images/hero.jpg`-এ হোমপেজের ব্যাকগ্রাউন্ড ছবি দিন।
4. GitHub → Settings → Pages → Deploy from branch → main → /root নির্বাচন করুন।
5. পরে Google Forms/Sheets সংযোগের জন্য `membership.html` আপডেট করুন।
